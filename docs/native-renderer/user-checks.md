New captures land in that directory's `logs` folder. The three captures sub-project 5's table entries were accepted on (`native_discovery_20261005_103213`, `native_discovery_20261005_123635`, `native_discovery_20261006_110021`, each with its `native_geo_<stamp>` folder) are also copied to `out\native-evidence\` (792 MB, git-ignored like all of `out`): a recreated build directory does not lose them, a deleted `out` does.
